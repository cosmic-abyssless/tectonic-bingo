# Tectonic Bingo

## Git

### Features

#### Starting

Before starting work on a new feature, make sure you fetch and pull main before branching off of it.

#### Finishing

Once you are done with work on a feature and have made a PR. Confirm with the user that it is safe to delete the branch locally and move back to main.

## Glossary

`CONTEXT.md` defines the canonical domain terminology for this project (roles, board/tile/part/task structure, submissions, scoring, etc.). Read it when working on anything where the precise term or its rules matter — otherwise skip it.
